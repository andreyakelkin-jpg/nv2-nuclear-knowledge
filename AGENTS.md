# Project instructions

## Publishing plugin changes

- After completing and successfully validating any requested change to this plugin, automatically commit the task-scoped changes and push the commit to the configured GitHub remote. Do not wait for a separate request to publish.
- Synchronize with the remote branch before pushing. Never force-push, rewrite shared history, or include unrelated working-tree changes.
- If validation, authentication, synchronization, or the push fails, preserve the local changes and report the exact blocker to the user.
