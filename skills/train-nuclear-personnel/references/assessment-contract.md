# Assessment contract

Each item must contain:

```yaml
id: q-role-topic-001
type: single_choice | multiple_choice | short_answer | document_navigation | case
role: quality_engineer
competencies: []
source:
  document_id: null
  anchor: null
  page: null
question: null
correct_answer: null
explanation: null
critical: false
```

Recommended assessment mix:

- 35% knowledge of requirements;
- 30% locating and applying the correct clause;
- 25% situational decision;
- 10% evidence quality and citation.

Record score, critical errors, competence gaps, retraining actions, assessor, source versions, and next assessment date.
